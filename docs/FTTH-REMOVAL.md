# FTTH removal gate
- Original upstream is immutable at original/FiberLens.
- atlas-mobile is a separate working copy.
- FTTH features must be isolated by tracing their routes, stores, imports, tests, and data schemas before removal.
- Keep shared CAD/DWG, map, coordinate, geometry, file, and Android infrastructure.
- No claim of FTTH removal or working APK until typecheck, build, tests and Android assembly pass.
- Review upstream license notices and third-party dependencies before distribution.
